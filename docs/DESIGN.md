# Дизайн-система сторінки проєкту · 1.1.0

## Принцип

Відкрито показуємо ключові цифри, повну назву проєкту та короткі описи напрямів. Повні тексти, пріоритети, форуми, воркшопи, адвокаційні результати й перелік інформаційних матеріалів доступні через «Докладніше». Редактура структури не змінює факти чи терміни джерел.

## Макет і компоненти

- Максимальна ширина 1320 px, поля 56 / 32 / 24 / 20 px. Вертикальні відступи секцій 104 / 64 px.
- Шапка компактна. Розміри фіксованої кнопки звірені з CSS головної: висота 52 px, висота повного логотипа 26 px; ширина близько 278 px. Лого й гамбургер — одна кнопка. Меню містить тільки розділи сайту та пошук.
- Перший екран: повна офіційна назва, точний короткий опис, реальна фотографія, 23 області та метадані партнера.
- «Про проєкт»: три чіткі тези на всю ширину, короткий опис 24 px; географія й повний опис відкриваються окремо.
- Ключові результати: чотири великих показники у сітці 2×2; на mobile — послідовно.
- Напрям: заголовок і короткий опис поряд із фото, а всі три показники — нижче на всю ширину секції. На вузьких екранах показники складаються у вертикальні рядки.
- Розгортання: єдина зелена кнопка «Докладніше», жовтий плюс, коротка підказка рухом один раз. При відкритті абзаци плавно з’являються; довгий текст читається в одну колонку. Галереї мають великі зображення природних пропорцій.
- Велике фото форуму посеред сторінки збережено. Фото без crop; на mobile заголовок розташований під фото, не поверх облич.
- Портал: опис і 4 можливості за скриншотом користувача. Дорожня карта — окремий короткий блок із великим фото.
- Перед футером лише дисклеймер із вбудованим посиланням УВКБ ООН та кнопка «На початок сторінки». Футер повторює структуру головної сторінки, без X.

## Рух і доступність

Одноразова поява першого екрана, спокійна поява розділів, лічильники 1200 ms, поабзацне розкриття 480 ms зі стислим stagger. Для руху використовуються opacity і transform; немає паралаксу та нескінченних ефектів. За prefers-reduced-motion — кінцеві значення й текст без руху. Нативні details і dialog, семантичні заголовки, видимий фокус, alt, Escape, модальний фокус та відновлення прокручування. Основний контент доступний без JS.

## Текстові джерела

Повні описи з Google Документа й уточненої сторінки збережені; прямі правки користувача й PDF мають пріоритет. Зокрема, 27 громад уже отримали підтримку, а 1 125 учасниць та учасників — загальний показник навчань; 554 — відвідувачі саме семінарів. Форумів та воркшопів не вилучено: вони всередині «Докладніше» відповідного напряму, без дубльованих зовнішніх переліків.
