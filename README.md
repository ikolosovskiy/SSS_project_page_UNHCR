# Сторінка проєкту БФ «Стабілізейшен Суппорт Сервісез» · 2026

Адаптивний дизайн: брендова палітра, локальні Manrope / Onest, 13 оригінальних фотографій, п’ять напрямів роботи, повні тексти в розгортаних блоках та вісім корисних матеріалів.

## Перегляд

Відкрийте `index.html` у браузері або запустіть:

```sh
node scripts/serve.mjs
```

Адреса: http://127.0.0.1:4173. Node.js 20+, встановлення залежностей не потрібне.

## Редагування

- `page.template.html` — композиція й короткі тексти.
- `research/content-updated.html` — уточнений текст із наданої сторінки GitHub Pages.
- `research/content.md` — попередній Google Документ, використаний для посилань на матеріали.
- `scripts/build.mjs` — глави, статистика та генерація готових HTML-файлів.
- `style.css` — дизайн, адаптивність та анімації.
- `main.js` — меню, навігація, поява розділів та поширення.
- `docs/DESIGN.md` — пояснення дизайн-системи.

Після змін:

```sh
node scripts/build.mjs
node scripts/check.mjs
node --check main.js
```

`index.html` і `page-content.html` включені до репозиторію: сторінку можна показувати через GitHub Pages без додаткової збірки. Публікація не виконувалася.

## WordPress

1. Скопіюйте папку як `wp-content/plugins/sss-project-page/`. Для роботи потрібні лише `sss-project-page.php`, `page-content.html`, `style.css`, `main.js` та `assets/`.
2. Активуйте плагін **SSS Project Page 2026**.
3. Додайте блок «Короткий код»: `[sss_project_2026]`.
4. Виберіть шаблон теми на всю ширину без бокової колонки. Приберіть дубльований заголовок сторінки засобами теми.

За замовчуванням зберігаються шапка та футер чинного сайту. `[sss_project_2026 chrome="own"]` показує шапку та футер макета; цей режим призначений для порожнього шаблону теми.

Фіксований блок «Меню + SSS» залишається доступним і в режимі шапки теми. Він відкриває повноекранне меню розділів проєкту, посилання на розділи сайту та пошук. Відступ зверху можна налаштувати через `--sss-menu-top` у `.sss-project`. Панель підтримує клавіатуру, Escape та повернення фокусу.

Для липкої шапки теми задайте `.sss-project { --sss-sticky-top: 80px; }` і відповідний `scroll-margin-top` для якорів у дочірній темі. Стилі обмежені `.sss-project`, назви шрифтів ізольовані. Плагін не змінює БД і не робить зовнішніх запитів. Одна копія шорткоду на сторінку.

PHP та WordPress локально не встановлені. Інтеграцію з чинною темою потрібно перевірити на staging перед установленням на основний сайт.
