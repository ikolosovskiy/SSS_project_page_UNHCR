# Сторінка проєкту БФ «Стабілізейшен Суппорт Сервісез» · 2026

Адаптивний дизайн: брендова палітра, локальні Manrope / Onest, 13 оригінальних фотографій, п’ять напрямів роботи, повні тексти в розгортаних блоках та вісім корисних матеріалів.

## Перегляд

Відкрийте `index.html` у браузері або запустіть:

```sh
node scripts/serve.mjs
```

Адреса: http://127.0.0.1:4173. Node.js 20+, встановлення залежностей не потрібне.

## Редагування

- `page.template.html` — композиція й короткі тексти.
- `portal.html` — блок Порталу Рад ВПО за погодженим референсом.
- `research/content-updated.html` — уточнений текст із наданої сторінки GitHub Pages.
- `research/content.md` — попередній Google Документ, використаний для посилань на матеріали.
- `scripts/build.mjs` — глави, статистика та генерація готових HTML-файлів.
- `style.css` — дизайн, адаптивність та анімації.
- `main.js` — меню, навігація, поява розділів та поширення.
- `docs/DESIGN.md` — пояснення дизайн-системи.

Після змін:

```sh
node scripts/build.mjs
node scripts/check.mjs
node --check main.js
```

`index.html` і `page-content.html` включені до репозиторію: сторінку можна показувати через GitHub Pages без додаткової збірки. Публікація не виконувалася.

## WordPress

1. Скопіюйте папку як `wp-content/plugins/sss-project-page/`. Для роботи потрібні лише `sss-project-page.php`, `page-content.html`, `style.css`, `main.js` та `assets/`.
2. Активуйте плагін **SSS Project Page 2026**.
3. Додайте блок «Короткий код»: `[sss_project_2026]`.
4. Виберіть шаблон теми на всю ширину без бокової колонки. Приберіть дубльований заголовок сторінки засобами теми.

За замовчуванням зберігаються шапка та футер чинного сайту. `[sss_project_2026 chrome="own"]` показує шапку та футер макета; цей режим призначений для порожнього шаблону теми.

Фіксована кнопка з повним логотипом фонду залишається доступною і в режимі шапки теми. Натискання на будь-яку частину кнопки відкриває меню лише розділів сайту та пошук. Навігація розділами проєкту розміщена окремо в самій сторінці. Відступ зверху можна налаштувати через `--sss-menu-top` у `.sss-project`. Панель підтримує клавіатуру, Escape та повернення фокусу.

«Докладніше» — нативні розгортані блоки: одноразова підказка рухом привертає увагу до кнопки, при відкритті текст з’являється абзацами. За reduced motion рух вимкнений, без JavaScript усе доступне через стандартні details.

Для липкої шапки теми задайте `.sss-project { --sss-sticky-top: 80px; }` і відповідний `scroll-margin-top` для якорів у дочірній темі. Стилі обмежені `.sss-project`, назви шрифтів ізольовані. Плагін не змінює БД і не робить зовнішніх запитів. Одна копія шорткоду на сторінку.

PHP та WordPress локально не встановлені. Інтеграцію з чинною темою потрібно перевірити на staging перед установленням на основний сайт.

## Новини проєкту

Шість новин — статичний знімок поточної сторінки фонду від 12.11.2026. Заголовки, дати, посилання та джерельні URL фото збережені в research/project-news.json; локальні фото — assets/news/. Для оновлення змініть JSON і відповідні зображення та запустіть node scripts/build.mjs. Автоматичної синхронізації з WordPress немає. Кнопка всіх новин веде на https://sss-ua.org/news/?project=36154.

Розгортання й згортання спойлера анімує висоту протягом 680 ms, абзаци з’являються послідовно. Режим reduced motion вимикає обидві анімації.

Зміст сторінки — окремий нативний спойлер, закритий на desktop і mobile. Відкривається за 440 ms, посилання з’являються послідовно; поточний номер позначено жовтим акцентом. Без JS він працює як стандартний details. У хедері — навігація за відеореференсом, EN, підтримка та кнопка пошуку, що фокусує пошук у меню сайту. Ліва кнопка з логотипом статична.

Ключовий опис «Про проєкт» і всі 5 пріоритетних напрямів відображаються відкрито. Кожен напрям має одноразову появу при прокручуванні; без JS і за reduced motion текст одразу доступний. Зміст сторінки, географія та детальні звіти напрямів залишаються спойлерами.

## Мапа України

Спойлер «23 області» містить векторну мапу з усіма областями та окремим Києвом. Підтримано збільшення, перетягування, стрілки клавіатури та повернення до 100%. Геодані й атрибуція — assets/maps/; джерело та ODbL: assets/maps/README.md. node scripts/build.mjs генерує SVG локально й виділяє рівно 23 області з regionNames. Звичайна збірка не потребує мережі.

На мапі немає постійних підписів: лише назва області в картці при наведенні, торканні або фокусі клавіатурою. Інформація про ради ВПО не відображається. Київ має окремий маркер. Без JS працюють нативні SVG-підказки.

Актуальна мапа 1.6.0 використовує Natural Earth (public domain), без обов’язкового підпису джерела. Крим показано одним контуром разом із Севастополем, без окремої межі міста. Легенду, інструкції та кредит під мапою прибрано. Джерело й відтворення — assets/maps/README.md; попередні примітки про ODbL стосувалися заміненої версії.

Другий раунд редакційних правок (1.7.0): docs/PDF-REVIEW-2.md. Портал — окремий третій напрям; усі напрями мають номери 1–7, зміст — 10 пунктів. Фото мають підписи, кухня показана парою до/після. Приклад дорожньої карти й оригінальний PDF розміщені в assets/documents/.
